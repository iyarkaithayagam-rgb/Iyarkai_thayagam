# Iyarkai Thayagam Arakkattalai (இயற்கை தாயகம் அறக்கட்டளை)

Bilingual NGO Website for **Iyarkai Thayagam Arakkattalai**, a registered public trust working across environmental protection, water body restoration, organ donation awareness, animal welfare, and tree plantation in Tamil Nadu.

## Features
- **Bilingual Interface**: Seamless 1-click toggle between English and Tamil (EN / தமிழ்).
- **Responsive Modern Design**: Optimized for Desktop, Mobile, and Tablet viewports.
- **Palm Tree Mission Tracker**: Interactive 1,00,000 palm tree mission progress bar & counter.
- **5 Focus Pillars**: Dedicated pages for Environment, Water Bodies, Organ Donation, Animal Welfare, and Tree Plantation.
- **Leadership Directory**: Complete showcase of 12 trust leaders and regional heads.
- **Embedded Media**: YouTube playlist integration and social media gallery.
- **Donation Impact Calculator**: Interactive slider demonstrating real ground impact per contribution.

## How to Run Locally
Open `index.html` directly in any web browser (Chrome, Safari, Edge, Firefox), or deploy to Netlify/Vercel/GitHub Pages.
